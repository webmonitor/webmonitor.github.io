WebMonitor

关注变化，不必反复刷新。

一个可自行部署的网页监控开源组织。把页面上的价格、公告、库存与截止日期交给它盯着，发生变化时通过邮件送达。 两种监控方式：在可视化工作台里逐项配置，或者用一句话把需求说清楚。

Projects

两个项目

同一套目标，两种入口：手动配置的监控工作台，与对话创建的监控助手。

WebMonitor

可视化工作台

用 XPath 框定页面上真正关心的区域，设置检查频率，内容变化时收到邮件。包含公开任务与订阅、任务与运行日志管理、中英双语界面， 单体容器即可部署，不依赖 AI 服务或模型密钥。

  • Python · FastAPI
  • Selenium
  • React
  • Docker
  • CC BY-NC 4.0

WebMonitor-Agent

对话式监控

粘贴链接，用自然语言说明要看什么、多久看一次、什么条件下通知。助手先分析真实页面，生成配置草稿并预览一次实际采集结果， 确认之后才创建版本化的监控。支持静态页面与浏览器渲染页面，记录变更事件、运行历史与采集证据。

  • Python 3.12 · FastAPI
  • Playwright
  • PostgreSQL
  • Next.js
  • MIT

Get Started

本地运行

两个项目都以 Docker 为第一运行方式，宿主机只需要 Docker Engine 与 Compose。

# WebMonitor-Agent
git clone https://github.com/webmonitor/WebMonitor-Agent.git
cd WebMonitor-Agent
cp .env.example .env
docker compose up --build --wait
# → http://localhost:8080

# WebMonitor
git clone https://github.com/webmonitor/WebMonitor.git
cd WebMonitor
cp .env.example .env
docker-compose up -d
# → http://localhost:8000

Agent 需要 PostgreSQL 与 S3 兼容存储，启动前请按 .env.example 设置数据库密码、SECRET_KEY 与管理账号； 目前面向本地开发与评估，部署前请阅读项目文档中的数据保留说明。
